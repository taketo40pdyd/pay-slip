# 給料手帳

手取りを家賃・食費・貯金などに振り分けて、未配分額・貯金率・引き落とし予定をひと目で確認できる、給料日の家計管理ツールです。ブラウザだけで動く静的サイト(HTML 1ファイル)で、データは利用者自身のブラウザにだけ保存されます。

## 主な機能

- 手取りの振り分け、未配分額・貯金率・給料日までのカウントダウン
- 今日使える額(予算の残りを次の給料日まで日割り)、カレンダー表示、支出ログ(レシート写真つき)
- 臨時収入の記録、固定費・サブスクの一覧と年間コスト、年間集計、貯金目標の達成シミュレーション
- 給料日・引き落とし日の通知、電卓、PDF・CSV・バックアップの書き出し
- クラウド同期(任意。利用者自身の Firebase を使用)
- 新しい版の自動検知と更新ボタン、オフライン対応、ホーム画面への追加(PWA)

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります(Public)。
2. このフォルダのファイルを、リポジトリの**ルート**にそのままアップロードします。
3. リポジトリの **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main / (root)** にして Save します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

## 新しい版を出す

`index.html` の次の3か所を変えて、commit・push します。`sw.js` は変えなくて構いません。

1. `<meta name="app-version" content="…">` の値
2. 末尾付近のスクリプトにある `var APP_VERSION = "…";`(1と同じ値にします)
3. 同じ場所の `CHANGELOG` の先頭に、変更点を1項目追加

公開から数分後(GitHub Pages の反映待ち)、利用者のアプリが新版を検知して「更新」バナーを出します。データは消えません。

## クラウド同期を使う(任意)

同期は、利用者それぞれが自分の Firebase プロジェクトを用意して使います。設定はアプリの「設定 → クラウド同期」に貼り付けるだけで、リポジトリには鍵を含めません。

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作り、ウェブアプリを登録して `firebaseConfig` を控えます。
2. **Authentication** で「メール/パスワード」を有効にします。
3. **Authentication → 設定 → 承認済みドメイン** に `<ユーザー名>.github.io` を追加します。
4. **Firestore Database** を作り、ルールを次のようにします。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /payday/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

5. アプリの「クラウド同期」に `firebaseConfig` を貼り付け、メールアドレスで新規登録します。

## データの保存場所と注意

- 入力したデータは、各自のブラウザ(localStorage)に保存されます。レシート写真は同じブラウザの IndexedDB に保存され、バックアップやクラウド同期には含まれません。
- ブラウザのデータを消すとアプリのデータも消えます。「設定 → データ → 書き出す」で、時々バックアップを取ってください。
- 通知は、アプリを開いたとき・画面に戻ったときに確認して知らせます(アプリを閉じている間の通知は、サーバーを使わないため出ません)。
